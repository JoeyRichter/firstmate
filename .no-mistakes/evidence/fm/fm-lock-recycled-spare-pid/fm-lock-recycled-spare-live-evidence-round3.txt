### 4. Round-1 regression re-verified live: find_pid's comm-anchor fix (commit 91eae55) ###
A prior test round found tests/fm-session-lock-spare-live-e2e.test.sh's find_pid("spare")
could false-match a non-harness process merely because its argv TEXT contained
"--bg-spare ...claim.sock" (e.g. this gate's own orchestrator quoting the bug description).
Reproduced fresh with a real, live, crafted decoy process (not a stub):
  `/tmp/decoy_proc.sh --bg-spare /tmp/decoy-spare/fake.claim.sock &`
  -> real pid, comm="bash", args="bash /tmp/decoy_proc.sh --bg-spare /tmp/decoy-spare/fake.claim.sock"

  OLD find_pid matching logic (pre-91eae55, args-only, no comm check):
    decoy MATCHES as "spare"   <- reproduces the round-1 false positive against a real process
  NEW find_pid matching logic (current, anchored on fm_harness_process_matches(comm,args)):
    decoy correctly EXCLUDED (comm "bash" never matches FM_HARNESS_RE)

  Confirmed the anchor is not over-broad: the same NEW logic still matches a genuine live
  recycled spare (pid 8307, comm "claude bg-pty-host") found on the host at the same time.

Decoy process was killed and its script file removed immediately after use; no residue.

### 8b. Checked whether the find_pid comm-anchor (section 4) could also break the
    "session" branch, not just fix the "spare" branch ###
  fm_harness_process_matches's first evidence rule is a plain regex SUBSTRING match on
  comm alone (FM_HARNESS_RE), returning a match before ever inspecting args. A real
  bg-pty-host process has comm "claude bg-pty-host" whether it is actively hosting a
  session or sitting recycled in the idle pool - same comm either way, confirmed directly
  above: genuine live spare pid 8307 (section 4) and the deterministic suite's own explicit
  assertion (section 6's test_recycled_spare_is_not_live_but_active_host_is, which asserts
  `fm_harness_process_matches "claude bg-pty-host" "claude bg-pty-host --session-id f1
  --resume /x"` matches) both pass with the identical comm string. So the anchor can only
  ever exclude a NON-claude-named comm (exactly the round-1 false-positive class fixed in
  section 4); it cannot discriminate session vs. spare argv shapes and so cannot have
  regressed the session branch.
